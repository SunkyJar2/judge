HOW TO SUBMIT

  1. Type a problem code and choose a matching problem.
  2. Paste your C, C++, or Python solution in the editor.
  3. Press Submit & Run.
  4. Check the verdict in the status page.

JUDGE DETAILS

All paired input/answer files are tested, including secret tests.

Only your verdict and testcase results are shown. Hidden test data stays private.

Expected output is compared while ignoring whitespace between tokens.

This local judge is not a security sandbox. Never expose it to public users.

HOME › ADMIN

Administrator tools

PROBLEMSET MANAGERPublish a problem into a collection and manage inappropriate forum posts.

Add a problem

Add a text statement or a PDF. PDF and image uploads are optional; the image appears with the statement. Use a JSON array of input/output pairs. Set sample to true only for examples students may see. Up to 100 cases; each input/output is limited to 256 KB. Points are awarded once for the first accepted submission.

Edit a problem

Editing replaces the test set used by the judge. Mark only public examples with "sample": true. Up to 100 pairs, 256 KB per input and answer. PDF and uploaded problem image assets are preserved. Existing accepted points are unchanged.
